# Lightweight Browser

A fast, private desktop browser for Windows, macOS and Linux whose main goal is **using far less RAM than Chrome, Brave or Edge** without making you babysit your tabs. It uses the operating system's own web engine and hibernates background tabs intelligently, so tabs you're actually using (music, calls, half-filled forms) are never touched.

"Lightweight Browser" is a working name. The project is in early development and there's nothing to download yet. See [`docs/SPEC.md`](docs/SPEC.md) for the plan and [`docs/STATUS.md`](docs/STATUS.md) for progress.
